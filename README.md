# Tic Tac Toe

A browser-based Tic Tac Toe game built with vanilla JavaScript. Play against a friend locally or challenge the built-in AI opponent.

## Features

- Two game modes: two-player (pass and play) and single-player vs AI
- Clean, responsive UI
- Win/draw detection with instant game-over feedback
- Restart option to start a new round anytime

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla, no frameworks)

## How to Run

1. Clone the repo
2. Open `index.html` in your browser
3. Choose a mode and play

## What I Learned

Built this to practice DOM manipulation, event handling, and implementing basic game logic (win condition checks, turn switching, and a simple AI decision-making approach) without relying on any external libraries.
